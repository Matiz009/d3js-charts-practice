# D3.js Charts Practice

Bar, line and pie chart examples built while learning D3.js.

## Screenshot

_Screenshot coming soon._

## Features

- DOM selection and styling with `d3.select`, `d3.selectAll`, `append`, `attr` and `text` (`index.html`, `app.js`)
- Bar chart drawn as SVG from an array of values (`barchart.html`)
- Line chart (`lineChart.html`)
- Pie chart (`pieChart.html`)

## Tech stack

- D3.js v4 (loaded from d3js.org)
- HTML, CSS, JavaScript

## Getting started

No build step. Clone the repo and open any of the HTML files in a browser:

```bash
git clone https://github.com/Matiz009/d3js-charts-practice.git
cd d3js-charts-practice
# open index.html, barchart.html, lineChart.html or pieChart.html
```

An internet connection is needed because D3 loads from a CDN.

## Project structure

```
index.html / app.js           D3 selection and styling basics
barchart.html / barchart.js   Bar chart
lineChart.html / linechart.js Line chart
pieChart.html / piechart.js   Pie chart
styles.css
```
